# UI asset prompts (ChatGPT image)

The game draws a procedural UI by default. Drop PNG files with these exact names into
`app/src/main/assets/ui/` and the game uses them automatically. Every sprite must be a
square PNG with a transparent background, 256x256 (title: 1024x384).

Style for all prompts: stylized low-poly nature game UI, soft rounded shapes, warm
cream and leaf-green palette with a thin gold outline, subtle highlight on top edge,
flat vector look, no text, no letters, no numbers, centered, transparent background.

1. joy_base.png
   "Circular virtual joystick base for a mobile game, translucent frosted-wood ring with a
   thin gold outline and a leaf-pattern engraved inner groove, hollow center, stylized
   low-poly nature game UI, flat vector, 256x256, transparent background, no text."

2. joy_knob.png
   "Round joystick thumb knob for a mobile game, glossy leaf-green gem-like sphere with a
   soft highlight and a thin gold rim, stylized nature game UI, flat vector, 256x256,
   transparent background, no text."

3. btn_jump.png
   "Round jump button for a mobile game, cream-colored circular button with a thin gold
   rim and a bold green upward arrow icon in the middle, stylized nature game UI, flat
   vector, 256x256, transparent background, no text."

4. btn_gear.png
   "Round settings button for a mobile game, dark green circular button with a thin gold
   rim and a clean cream-colored gear icon in the middle, stylized nature game UI, flat
   vector, 256x256, transparent background, no text."

5. title.png (loading screen logo, 1024x384)
   "Game logo emblem for a cozy stylized low-poly nature exploration game, a rolling hill
   with an orange autumn tree, a green pine tree and a desert rock formation under a
   bright sky, a soft cream banner shape under it left blank, flat vector, transparent
   background, no text, no letters."

6. App icon (optional, 512x512, not loaded by the game)

   vector, no text."
